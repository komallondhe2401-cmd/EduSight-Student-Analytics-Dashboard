# EduSight — Student Analytics Dashboard

A ready-to-run React JS dashboard for student performance and dropout-risk analytics.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open it in VS Code.
4. Open Terminal and run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Tech stack
- React JS + Vite
- Recharts
- Lucide React
- Responsive CSS

## Resume description
**EduSight – Student Analytics Dashboard:** Built a responsive React dashboard to monitor student performance, attendance and dropout-risk indicators using interactive charts, filters, KPIs and risk-based recommendations.
